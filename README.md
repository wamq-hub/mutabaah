# متابعة مهام أعضاء هيئة التدريب — نسخة المتصفح

متابعة أسبوعية لمهام أعضاء هيئة التدريب (الثابتة والطارئة والإبداعية): لوحة القسم، ورسائل البريد، والتقارير، وإصدار ملفات المدربين وقفلها برقم سري.
يعمل كله داخل المتصفح (Pyodide)، وبيانات المستخدم لا تغادر جهازه.

هذا المجلد مولَّد بالأمر python web/build_web.py من مشروع البرنامج؛ لا يُعدَّل يدوياً.
